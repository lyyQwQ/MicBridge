# Typeless 录音自动启停与设备记住配对

## 目标

通过监测 VB-Cable 录音端点 CABLE Output 的 WASAPI 会话，自动启停 Android 端眼镜麦克风录音；移除被自动启停取代的全局快捷键；将 6 位配对码流程替换为首次允许、长期记住设备的配对与自动重连体验。

负责人：lyyQwQ。优先级：P1。

## 需求

### R1：录音自动启停

- 核心监测对象为 VB-Cable 录音端点 CABLE Output 的 WASAPI 会话。
- 任一非本进程会话 State=Active，即视为有人在听写；不限定 Typeless 进程，其他应用使用该端点同样适用。本进程的会话不计入触发判断，Inactive 会话不触发录音。
- 检测到上述活动状态时，若 Android 已连接且空闲，则发送 START，开启录音。持续 Active 不应重复触发启动。
- 所有纳入判断的会话均非 Active 持续 1 秒后，发送 STOP，停止录音；1 秒内任一会话重新 Active 时取消待停止动作，避免连续听写抖动。
- 手动开始与手动停止仍然可用。
- CABLE Output 不存在时记录该状态；端点重新出现后恢复监测与自动启停。

### R2：移除全局快捷键

- 移除全局快捷键 Ctrl+Shift+Space 的注册及相关处理。该快捷键注册失败，其使用场景由自动启停替代。
- 同步删除产品 UI 和文档中的快捷键文案，清理相关代码残留。

### R3：设备记住配对

- 首次由手机发起连接时，Windows Flutter 弹出「允许 <设备名> 连接？」确认提示，用户允许后建立可信配对关系；未经允许的设备不得建立可信连接。
- 允许后两端保存长期密钥：Windows 使用 DPAPI 保护，Android 使用 Keystore 保护。
- 已记住的手机以后自动重连，无需再次输入信息；双方程序重启后，配对信任仍然有效。
- 移除 6 位配对码输入流程。
- 提供「忘记设备」能力；忘记后，原设备再次连接需要重新允许。
- 仍只支持一台手机，不扩展为多手机并发或多手机管理。
- 修复手机端改码重试时 ControlClient.connect 因 running 未复位而直接返回的问题，确保连接失败后可以再次发起连接；移除配对码流程后仍应保证连接重试有效。

## 非目标

- 多手机支持。
- 云服务与账号体系。
- 自定义虚拟声卡驱动。
- 托盘功能。

## 验收标准

### R1：自动启停与回退能力

- [ ] 单元测试覆盖上升沿启动：从没有有效 Active 会话变为存在非本进程 Active 会话时，在 Android 已连接且空闲的条件下发送 START。
- [ ] 单元测试覆盖防抖：全部会话非 Active 后，1 秒内重新出现 Active，不发送 STOP。
- [ ] 单元测试覆盖停止：全部会话持续非 Active 超过 1 秒后发送 STOP。
- [ ] Inactive 会话及本进程会话不触发启动；非 Typeless 应用的有效 Active 会话同样可以触发。
- [ ] 持续 Active 不重复启动；Android 未连接或非空闲时不发送启动指令。
- [ ] CABLE Output 缺失时有状态记录，设备出现后可以恢复自动启停。
- [ ] 手动开始与手动停止均仍可用。
- [ ] 真机验证：Typeless 开始听写时眼镜麦克风开启，听写结束约 1 秒后释放蓝牙 SCO。
- [ ] 真机验收记录首字是否丢失、复现条件及观察结果。

### R2：快捷键清理

- [ ] 相关代码和 UI 中不再保留 Ctrl+Shift+Space 全局快捷键的注册、处理与提示。
- [ ] 产品使用文档同步删除该快捷键说明；本任务中用于描述移除要求的文字不属于产品快捷键残留。

### R3：信任保存与重新配对

- [ ] 首次手机连接时，Windows Flutter 显示包含设备名的允许提示；允许后可正常连接。
- [ ] Windows 和 Android 分别使用 DPAPI、Keystore 保护长期密钥。
- [ ] 首次允许后，重启双方程序仍能自动连接，无需输入配对码或再次确认。
- [ ] 两端连接流程不再要求输入 6 位配对码。
- [ ] 执行「忘记设备」后，该设备再次连接需要重新允许。
- [ ] 连接失败后可重试，ControlClient.connect 不会因 running 未复位直接返回；原改码重试问题得到修复。
- [ ] 支持范围仍为单台手机。

## 已知风险

- 蓝牙 SCO 建立通常需要 0.5–2 秒，自动启动录音可能导致开头丢字；真机验收必须记录首字丢失情况。
- Android 后台或锁屏状态下启动麦克风受到系统限制，可能影响自动启停体验；真机验收应记录相关状态与现象。
